# H-Lab — hcu-lab.me

Official homepage and engineering portfolio of Hai Duong Nguyen, based in Japan.

- [Public site](https://hcu-lab.me/)
- [Original Hport landing page](https://hcu-lab.me/hport/)
- [H-Lab portfolio project](https://hcu-lab.me/h-lab-portfolio/)

Built with plain HTML, CSS, and JavaScript. No runtime dependencies or build tooling. The hero system diagram is an original illustration and is not an application screenshot.

## QA

Run `node --check script.js`, `node test.js`, `git diff --check`. Verify keyboard navigation, menu, system tabs, and desktop/mobile layouts in an isolated browser. Existing Cloudflare DNS and GitHub Pages CNAME are preserved. The old Hport landing page and QR asset remain available under `/hport/`.
